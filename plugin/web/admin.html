节点与结果

安装操作从本项目固定版本 Release 下载并校验采集器，仅在主动点击后执行。采集需要原始 ICMP 套接字权限；结果不代表去程或全国所有同运营商用户。

“仅见目的网”是什么意思？

只识别到一个电信 AS4134 或联通 AS4837 响应跳点，证据不足以确认骨干线路。它不等于线路差、故障或丢包，也不能据此判断 163、4837、9929。中间路由器可能不回复探测；可查看详情中的逐跳证据，或更换同运营商目标后重测。
